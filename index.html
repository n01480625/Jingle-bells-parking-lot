Introduction

Parking in busy areas can be challenging, especially when drivers have to spend extra time searching for available parking spaces. This can lead to traffic congestion, wasted time, and unnecessary fuel consumption. Our project aims to address this problem by developing an Arduino Uno Smart Parking Guidance System that automatically monitors parking spaces and guides drivers toward the closest available spot.

The system uses an Arduino Uno as its main microcontroller, which processes information collected from presence sensors installed in individual parking spaces. These sensors detect whether a parking space is occupied or empty and send the information to the Arduino. Based on the collected data, the system determines which parking spaces are available and identifies the closest suitable spot for incoming drivers.

To make the system easy to understand and operate, two different LED colours are used to communicate parking information. Green LEDs indicate available parking spaces, while red LEDs show occupied spaces. This visual guidance helps drivers quickly recognize available parking spots without having to check every space individually.

In addition, the project includes a motor-operated mechanism that will represent an automatic entrance barrier. When a vehicle approaches the parking entrance, the motor can control the barrier to allow or restrict access depending on parking availability. A 16×2 LCD display will provide real-time information, such as the total number of available spaces and their locations. If all parking spaces are occupied, the display will show a "PARKING FULL" message to notify incoming drivers.

Throughout the development process, we may face several challenges that could affect the completion of the project. These include limited time, budget restrictions, and a lack of experience with Arduino programming and electronic components. Some sensors may not detect vehicles accurately, and connecting multiple components while ensuring that they work together correctly may require additional testing and troubleshooting. There is also a possibility that certain components, such as the automatic entrance barrier, may not operate as expected. To overcome these difficulties, we plan to test individual components separately, simplify the programming when necessary, and consider alternative solutions. For example, if the original gate mechanism proves too difficult to implement, we can use a basic servo motor to create a simpler working barrier. We will also prioritize the main parking detection and guidance functions if time or resources become limited.

The main goal of this project is to demonstrate how microcontrollers, sensors, motors, LED indicators, and programming can be combined to create a practical automated parking solution. By building a miniature working model, we hope to show how technology can make parking more organized, convenient, and efficient while reducing the time drivers spend searching for available spaces.

Arduino Code

The following Arduino code controls the system, lighting LEDs and activating the buzzer based on distance readings from the HC-SR04 sensor.

 
  
// Collision Warning System with Distance Sensor (HC-SR04)
// Author: Ana Rodrigues
// Oct 2, 2025
// Object is farther than 50cm: Green LED lights up
// Object is closer than 50 cm, but more than 10cm away: Yellow LED lights, buzzer plays 300Hz tone
// Object is closer than 10cm: Red LED lights up, buzzer plays 500Hz tone

//LED pins
const int greenLED = 2;
const int yellowLED = 3;
const int redLED = 4;

// Ultrasonic sensor pins
const int trigPin = 9;
const int echoPin = 10;

// Passive buzzer pin
const int buzzer = 11;

void setup() {
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  // Measure distance
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  long distance = duration * 0.034 / 2;

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");
  
  //Error in measurement:
  if (distance <= 0)
    return;

  //Too close:
  if (distance <= 10) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, HIGH);
    tone(buzzer, 500); // Play 500Hz tone
    return;
  }

  //Midrange:
  if (distance <= 30) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, HIGH);
    digitalWrite(redLED, LOW);
    tone(buzzer, 300); // Play 300Hz tone
    return;
  }

  //Normal status:
  digitalWrite(greenLED, HIGH);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
  noTone(buzzer); // stop buzzer

  delay(100);
}

Conclusion

The system effectively demonstrates distance-based alerting using Arduino. It’s affordable, educational, and sustainable through reusable components.
